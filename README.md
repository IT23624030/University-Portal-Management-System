# University-Portal-Management-System

UniHub is an enterprise-grade platform built to solve the fragmentation of university services. It integrates academic support, facility management, and campus life into a single, high-performance interface.

✨ Key Modules:

🏙️ Smart Facility Booking: Real-time reservation for labs, lecture halls, and study spaces with automated maintenance tracking and issue reporting.

🤝 Kuppi & Skill Share: A peer-to-peer mentoring engine and skill-sharing marketplace to foster collaborative learning.

📅 Event Command Center: A data-driven dashboard for organizers to manage university events, track reach, and handle registrations.

🔍 Lost & Found Protocol: A secure, QR-coded handover system with automated email alerts and a campus bounty reward engine.

💼 Internship & Career Hub: A premium interface for students to discover, track, and apply for internships seamlessly.

📊 Operational Analytics: Real-time telemetry and reporting for administrative transparency.



🛠️ Tech Stack:
Frontend: React 19, Tailwind CSS v4, Framer Motion (for premium animations), Vite.

Backend: Node.js, Express.js, Socket.io (Real-time updates).

Database: MongoDB with Mongoose ODM.

AI Integration: Google Gemini & OpenAI for smart indexing and assistance.

Notifications: Nodemailer (SMTP) and automated CRON jobs.
